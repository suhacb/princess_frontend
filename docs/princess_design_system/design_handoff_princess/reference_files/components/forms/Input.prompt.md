One-sentence: Material 3 outlined text field with a floating label, optional prefix icon, error and hint states — the standard input across all Princess forms and dialogs.

```jsx
<Input label="Project name" placeholder="e.g. Office Relocation" />
<Input label="Search projects" icon="search" />
<Input label="Reference" error="Reference is required" />
```

Pair with `Select`, `Checkbox`, `Switch` for full forms. Controlled (`value`+`onChange`) or uncontrolled (`defaultValue`).
