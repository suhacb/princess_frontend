One-sentence: The azure-tinted surface Princess uses to propose an action, pre-fill an item, or surface an insight from project data — gradient spine, `auto_awesome` mark, and apply/dismiss actions.

```jsx
<AISuggestionCard
  title="3 risks have no mitigation owner"
  onAccept={assignOwners} onDismiss={hide}>
  Assign the project manager as interim owner so these threats stay tracked until reassigned.
</AISuggestionCard>
```

Pair with `AIAssistButton` ("Ask Princess") for inline, on-demand assistance. AI surfaces always use the brand gradient + `auto_awesome` — never plain primary — so they read as machine-proposed, not user-authored.
